# Support

## How to Get Help

For questions, setup issues, or guidance:
- Open an issue with project path and details
- Include logs, steps attempted, and screenshots if relevant

## Contact Paths

Use repository issues for general support.
For security-sensitive reports, follow SECURITY.md and mark clearly as security-related.

## Recommended Issue Format

- Project: <folder path>
- Environment: OS, runtime, versions
- Problem: short description
- Steps to reproduce:
- Expected result:
- Actual result:
- Artifacts: logs/screenshots

## Response Notes

Support is best-effort and prioritized by:
1. Reproducibility
2. Severity
3. Scope impact
