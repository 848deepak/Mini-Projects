# CC-01: Personal Portfolio Website on EC2

This repository contains the interactive demo UI simulating a static personal portfolio and the step-by-step documentation for deploying it on an AWS EC2 instance running Apache.

## Motivation & Architecture
Implementing a simple AWS deployment is an essential step towards mastering Cloud Computing fundamentals. This project takes a cleanly designed, interactive static portfolio and illustrates how it lives on an EC2 server.

- **Frontend**: HTML5, CSS3 + Variables, Vanilla JavaScript
- **Infrastructure**: AWS EC2 (t2.micro), Apache Web Server, Security Groups

## Deliverables
1. `/website`: The front-end portfolio. Just open `index.html` in your browser.
2. `/aws-setup`: Detailed documentation for AWS EC2 creation, Apache installation, and deployment configurations (`setup-guide.md` and `apache-config.conf`).
